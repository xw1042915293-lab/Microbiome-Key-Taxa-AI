## 5. 异常用例

| 编号 | 场景 | 预期行为 |
|---|---|---|
| ET-01 | 缺少任一输入文件 | 阻止创建可运行任务或明确提示缺失项 |
| ET-02 | 缺少 `SampleID` 或 `FeatureID` | 数据检查返回错误并阻断分析 |
| ET-03 | 丰度包含文本、缺失样式值或负数 | 标出具体问题单元格并返回错误 |
| ET-04 | 样本或特征无法对齐 | 返回对齐错误或警告，不静默丢弃关键数据 |
| ET-05 | 未选择有效分组变量 | 阻止需要分组的分析并提示用户设置 |
| ET-06 | 无显著差异 | 保存完整结果和空显著表，明确说明无显著结果 |
| ET-07 | 网络无满足阈值的边 | 保存稳定结构或明确空网络状态 |
| ET-08 | 大模型未配置或调用失败 | 保留本地解释和统计结果，记录跳过或失败原因 |
| ET-09 | Quarto 不可用 | 保留分析产物并记录报告失败信息 |
