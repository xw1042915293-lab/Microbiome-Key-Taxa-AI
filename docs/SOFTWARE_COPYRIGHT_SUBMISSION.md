# 软件著作权申报材料说明

## 1. 文档用途

本文档用于整理“微生物组关键菌筛选与可信解释系统 V1.0”的软件著作权登记材料。它给出可直接复用的软件简介、功能说明、技术特点和材料清单；申请主体、完成日期及发表状态等事实信息应由申请人在提交前确认。

软件基本信息和术语以 `docs/SOFTWARE_PROFILE.md` 为准。

## 2. 软件概述

微生物组关键菌筛选与可信解释系统 V1.0 是一套基于 R Shiny 的微生物组数据分析应用。系统接收丰度表、样本信息表和分类注释表，通过图形化界面完成数据质量检查、多样性分析、差异丰度分析、机器学习特征筛选、共现网络分析和关键菌综合评分，并将统计表格、图形、结构化摘要、解释文本和分析报告统一保存。

系统面向需要减少脚本操作、规范分析过程并集中管理结果的科研用户。每次分析均创建独立任务目录，保存输入副本、关键参数、运行状态和输出文件，便于复核、展示与复现。

## 3. 开发目的

传统微生物组分析通常由多个脚本和软件工具共同完成，输入文件、参数、图表和文字说明容易分散。系统的开发目的包括：

- 将常用分析步骤组织为可操作、可检查的标准流程；
- 在分析前统一检查输入格式及样本、特征对应关系；
- 将一次运行的输入、参数和结果保存为独立任务单元；
- 融合差异、机器学习和网络证据，对关键菌候选进行排序；
- 限制自动解释的输入范围和结论边界，降低过度表述风险；
- 自动汇总表格和图形，形成可交付的分析报告。

## 4. 主要功能

| 编号 | 功能 | 说明 |
|---|---|---|
| F01 | 数据导入与任务创建 | 导入三类数据表，创建独立任务目录并固化输入副本 |
| F02 | 数据质量检查 | 检查必要字段、重复标识、缺失值、非数值或负值以及样本、特征对齐情况 |
| F03 | 参数管理 | 选择分组变量并保存分析参数和可复现信息 |
| F04 | Alpha 多样性分析 | 计算样本内多样性指标，生成统计表和组间比较图 |
| F05 | Beta 多样性分析 | 基于距离矩阵进行排序展示和 PERMANOVA 检验 |
| F06 | 差异丰度分析 | 在指定分类层级完成组间检验、多重校正和差异结果汇总 |
| F07 | 机器学习特征筛选 | 使用随机森林输出特征重要性和模型评价信息 |
| F08 | 共现网络分析 | 基于 Spearman 相关构建网络，输出节点、边和中心性指标 |
| F09 | 关键菌综合评分 | 融合差异、机器学习和网络证据，形成候选排序 |
| F10 | 受约束结果解释 | 基于结构化统计产物生成本地规则说明，并可选调用大模型生成受约束摘要 |
| F11 | 报告生成 | 使用 Quarto 汇总任务产物，生成 HTML 或 PDF 报告 |
| F12 | 任务与结果管理 | 查看历史任务、运行状态和产物，并下载报告、表格、图形或完整结果包 |

## 5. 技术特点

### 5.1 任务隔离与可追溯

系统为每次运行创建 `results/job_YYYYMMDD_HHMMSS_xxxxxx/` 目录。输入副本、表格、图形、JSON、解释文本、报告和日志均保存于该目录，避免不同任务的结果互相覆盖。

### 5.2 分析逻辑与界面分离

业务函数位于 `R/`，Shiny 页面模块位于 `modules/`。分析函数接收普通参数并返回普通 R 对象，使核心流程能够脱离浏览器界面进行测试和复用。

### 5.3 多证据关键菌排序

系统对差异显著性与效应量、随机森林特征重要性以及网络中心性进行归一化和加权融合。缺失某类证据时，按实际可用来源调整分母，减少缺失值对候选排序的影响。

### 5.4 受约束解释与审计留痕

解释模块读取统计结果和结构化摘要，不直接把原始丰度表交给大模型。规则要求不得改变显著性结论、不得将相关表述为因果、不得凭空补充机制；可选的大模型请求和响应以 JSON 保存，便于复核。

### 5.5 可复现报告

报告模块只汇总任务目录中已经落盘的产物，不在渲染阶段重新执行统计分析。输入校验值、关键参数及阶段记录保存于 `reproducibility.json`。

## 7. 输入与输出

### 7.1 输入

- 丰度表：包含 `FeatureID`，其余列为样本丰度且应为非负数值；
- 样本信息表：包含 `SampleID` 及至少一个可用分组变量；
- 分类注释表：包含 `FeatureID` 及一个或多个分类层级。

支持 `.tsv`、`.csv` 和 `.txt` 文本表格，推荐使用 UTF-8 编码的 TSV 文件。

### 7.2 输出

| 目录或文件 | 内容 |
|---|---|
| `input/` | 固化后的三类输入副本 |
| `alpha/` | Alpha 专属统计表及按指标、图形类型分类的 PNG/PDF |
| `beta/` | Beta 专属排序坐标、PERMANOVA、PERMDISP 和论文级 PNG/PDF |
| `tables/` | 数据检查、多样性、差异、机器学习、网络和评分结果表 |
| `figures/` | PNG/PDF 分析图形 |
| `json/` | 结构化统计摘要及可选模型调用记录 |
| `ai/` | 方法、图例和受约束解释文本 |
| `objects/` | 可复用的 R 数据对象 |
| `report/` | HTML/PDF 分析报告 |
| `logs/` | 运行记录和异常信息 |
| `reproducibility.json` | 输入校验值、参数和任务阶段记录 |

## 8. 软件边界

- 本软件调用开源 R 包完成底层统计计算，自研重点是业务流程、任务管理、结果融合、解释约束和报告组织。
- 系统结果用于统计关联分析和候选筛选，不直接证明生物学因果关系。
- 机器学习指标主要用于探索性评价，不等同于独立外部验证结果。
- 共现网络中的相关关系不代表直接生物相互作用。
- 自动生成的解释文本必须经过专业人员审核。
- 报告渲染依赖本机可用的 Quarto 环境；可选大模型能力依赖用户配置和网络环境。
