## 2. 软件定位

本软件面向微生物组丰度表、样本信息表和分类注释表，提供数据校验、多样性分析、差异丰度分析、机器学习筛选、共现网络分析、关键菌综合评分、受约束文本解释及可复现报告生成能力。

本软件是 microeco 等统计分析工具的上层应用，不替代其底层算法。自研部分主要体现在：

- 图形化业务流程与模块化交互界面；
- 输入校验、任务状态管理和异常处理；
- 独立任务目录及结果追溯机制；
- 多来源证据融合的 Key Taxa Score 工程化排序；
- 基于结构化统计结果的受约束解释流程；
- 分析产物汇总、下载和可复现报告生成。

## 3. 统一术语

| 统一术语 | 含义 | 不建议混用的表述 |
|---|---|---|
| 任务（job） | 一次独立的数据分析及其全部落盘产物 | 作业、实验、项目（指同一对象时） |
| 丰度表（abundance） | 特征为行、样本为列的非负数值表 | OTU 表（数据不一定是 OTU 时） |
| 样本信息表（metadata） | 包含 `SampleID` 及分组变量的表格 | 分组表、临床表（除非数据确属该类型） |
| 分类注释表（taxonomy） | 包含 `FeatureID` 及分类层级的表格 | 物种表（分类层级不确定时） |
| 分组变量（`group_var`） | 用户从样本信息表中选择的比较变量 | 标签、类别列（正式材料中） |
| 关键菌候选 | 由多来源证据排序得到的候选分类单元 | 已证实关键菌、致病菌 |
| 受约束解释 | 仅依据结构化统计结果生成的摘要性说明 | 自动科研结论、机制解释 |
| 可复现记录 | 输入校验值、参数、阶段状态等运行信息 | 实验日志（范围更窄） |

## 5. 表述边界

- 统计结果描述为“差异”“关联”或“探索性发现”，不直接表述为因果关系。
- 随机森林的重要性用于候选筛选，不代表生物学机制或因果效应。
- 共现网络的边表示统计相关，不代表直接相互作用。
- Key Taxa Score 是候选优先级排序指标，不等同于关键性的实验验证。
- AI 或规则文本是结果摘要与写作辅助，不能替代专业判断和人工审核。
- 软件可复现性指输入、参数、环境和产物可追溯，不代表不同软件版本或不同计算环境下结果必然完全相同。
